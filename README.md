# blvck Sync v0.4 — 4K only

Questa build:
- mostra solo release marcate 2160p / 4K / UHD;
- esclude 1080p, 720p e inferiori;
- mantiene il provider standalone compatibile con Nuvio;
- non introduce bypass di protezioni o controlli di accesso degli host.

Se un link restituito dal provider risponde 403, il problema è lato host/playback
e non viene aggirato da questa build.
